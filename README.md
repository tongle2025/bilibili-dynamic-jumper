# 哔哩哔哩动态日期跳转助手

一个轻量、简洁的 B 站动态历史跳转油猴脚本，帮助你快速定位到任意 UP 主（或动态首页）指定日期或年月的历史动态，无需手动无限下拉。

## ✨ 功能特性

- **两阶段智能查找**：点击搜索后先全量扫描页面已加载的动态——已加载范围内支持**零滚动**前后任意反复跳转（例如先查 7 月 1 日再查 9 月 30 日）；仅当目标更早时才自动向下滚动加载。
- **定位当日/当月最早动态**：自动加载完整目标时段，默认高亮并定位到该日期/月份**最早发布的一条**动态，避免停留在当日最后一条；同时支持**更晚一条 / 更早一条**快速切换同日多条动态。
- **精准时间解析**：优先读取动态卡片底层精确时间戳（`pub_ts`），并完整兜底解析 B 站所有展示格式（`刚刚`、`N秒前`、`N分钟前`、`N小时前`、`昨天 HH:mm`、`前天`、`2天前`/`3天前`、`MM月DD日`、`YYYY年M月D日`）。
- **自定义日历选择器**：扁平简洁风格日历控件，默认选中今日，支持年份/月份下拉快选与翻页；勾选“仅按年月”自动切换为 12 月网格视图。
- **自动跟随深色模式**：自动检测并实时跟随 **B 站官方深色模式**、**Bilibili-Evolved 夜间模式**及其他深色插件，无需刷新页面即可同步切换面板与高亮配色，也支持在设置中手动指定浅色/深色。
- **置顶动态兼容与设置持久化**：置顶动态不干扰历史时间边界判断，若日期正好命中仍会纳入结果；所有滚动与主题设置通过 `localStorage` 自动保存。

## 📦 安装方法

1. 在浏览器中安装 [Tampermonkey](https://www.tampermonkey.net/)（篡改猴）扩展。
2. [从 Greasy Fork 安装](https://greasyfork.org/zh-CN/scripts/552739-b%E7%AB%99%E5%8A%A8%E6%80%81%E6%97%A5%E6%9C%9F%E8%B7%B3%E8%BD%AC%E5%8A%A9%E6%89%8B)（或直接导入本仓库中的 `bilibili-dynamic-jumper.user.js`）。

## 🚀 使用说明

支持以下页面：
- UP 主个人动态页：`https://space.bilibili.com/*/dynamic*`
- 动态首页：`https://t.bilibili.com/*`

1. 打开动态页面后，点击右上角的 **「动态跳转」** 按钮展开控制面板。
2. 在 **「跳转」** 标签页中点击日期栏打开日历，选择目标日期（默认今日）；如需匹配整月，勾选 **「仅按年月」**。
3. 点击 **「开始搜索」**，脚本会自动检查已加载动态或向下滚动加载，完成后高亮并滚动至目标日期**最早的一条**动态。
4. 若当日/当月有多条动态，可在面板底部的 **「匹配结果」** 栏点击 **「更晚一条」 / 「更早一条」** 逐条浏览，或点击 **「清除高亮」** 恢复原样。
5. 若目标日期未发布动态，脚本会自动定位到时间最接近的一条动态并给出提示。

## ⚙️ 设置说明

在面板 **「设置」** 标签页中可按需调整（修改后自动保存，支持一键恢复默认）：

| 参数 | 默认值 | 说明 |
| :--- | :--- | :--- |
| **面板主题** | 跟随页面 | 自动跟随 B 站官方 / Bilibili-Evolved 深色模式，也可手动固定为浅色或深色 |
| **最大重试次数** | `10` 次 | 连续多次滚动未加载出新动态时停止；查找数年前的早期动态建议调至 `20~30` |
| **滚动等待时间** | `2000` 毫秒 | 每次滚动后等待新动态渲染的时长，网络较慢时可适当调大至 `2500~4000` |
| **滚动力度** | `激进` | 可选 `普通`（滚至底部）、`激进`（底部 + 额外滚动）、`极限`（连续三次超量滚动） |
| **额外滚动距离** | `2000` px | 配合激进/极限模式使用的额外下拉像素，帮助更稳定地触发懒加载 |

## 💡 注意事项

- 回溯数年前的历史动态需要加载大量页面内容，耗时较长，可在面板状态栏实时观察 `当前位置` 与 `已加载` 条数。
- 若滚动过快触发 B 站风控验证，完成验证后继续搜索即可；若长时间无新内容加载，可尝试调大等待时间或切换至“极限”模式。
